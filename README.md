# homebrew-memoratu

This is the [Homebrew](https://brew.sh) tap for `mu`, the command-line client
for [memoratu](https://github.com/subbutgs/memoratu-releases).

## Install

```
brew install subbutgs/memoratu/mu
```

## What this repo is

One formula (`Formula/mu.rb`) that points `brew` at the pre-built `mu`
binaries published in [memoratu-releases](https://github.com/subbutgs/memoratu-releases).

**The source code for `mu` and for memoratu is not public.** This repo and the
releases repo ship compiled binaries only — that is a deliberate choice, not a
gap. If you're looking for the source, there isn't a public copy to find.
